# DESIGO® — Design Style Library (55 styles × 20-phase build plans)

Status: documents first (2026-10-01). Build starts only after a style direction is approved.

Source: the client's two reference lists ("20 Design Styles" and the 29-style list). Duplicates were merged
(Clay style = Claymorphism · Surreal design = Surrealism · Editorial = Editorial Design · Y2K = Y2K Aesthetic ·
Collage art = Collage). Result: **36 styles**.

Each style document is a complete plan to build the **whole DESIGO® website** in that style:
same information architecture, same verified content, same Bottle360Viewer, different visual and interaction language.

## How every style document is structured
1. Style essence: what the style is, its origin, and three reference points
2. Why it fits DESIGO® (or where it fights the brand) plus a fit score from 1 to 5
3. Art direction: palette, typography, texture, imagery, iconography, grid
4. Motion & interaction language: scroll, cursor, hover, transitions, the bottle
5. How the hero bottle and the four variants (MASTER 26 · ROOT 14 · BASE 3 · ESSENTIAL) live in this style
6. Page-by-page treatment (Home chapters 01–15, /milk, /milk/[variant], /ghee, /origin, /trace, /technology, /about, /reserve)
7. Component list (style-specific variants of the shared components)
8. **20-phase build plan.** Each phase lists goal, deliverables, acceptance criteria and its dependency on supplied assets
9. Assets needed from DESIGO® for this style
10. Performance, accessibility and mobile notes
11. Risks and what to avoid in this style (and how to keep it premium)
